## 四、第三方接口声明

1. **第三方接口独立。** 各接口的内容、可用性、调用配额、隐私政策与使用条款均归其各自提供方所有。
   使用前请阅读对应提供方的服务协议及所在地区的法律法规。
2. **本项目不代理、不缓存、不存储任何接口业务数据。** 所有请求由你的浏览器或你自行运行的
   `serve.py` 直接发往目标 API；本项目不落库、不转发给任何第三方、不做统计分析。
3. **需鉴权的接口需自备凭据。** 原仓库中标注 `apiKey` / `OAuth` / `X-Mashape-Key` 的接口，
   需自行到对应平台申请密钥后方可调用。
4. **实测结果有时效性。** 页面上的响应码与耗时是**特定时间点的一次性快照**，
   不代表该接口当前或未来的状态。接口随时可能限流、改版或下线，请以官方文档为准。
5. **不构成任何担保。** 本项目按「现状」提供，不对数据的完整性、准确性、可用性作任何明示或默示担保。
   因使用本项目产生的任何直接或间接损失，作者不承担责任。
6. **合规使用。** 请遵守各 API 提供方的调用频率限制与使用条款，勿将其用于违法违规用途。
7. **商标与名称。** 「public-apis」为其社区所有；本项目名称「API 试炼场 / Public APIs Playground」仅用于标识本项目，
   与原仓库无隶属或背书关系。
